# AI 视频生成全能导演 Skill

> 一个面向 Claude 的 AI 视频生成系统提示词 Skill：把你的视频需求自动编译成专业、可执行、物理可信的视频模型提示词。

## 它能做什么

这个 Skill 让 Claude 扮演 **AI 导演 + 摄影指导 + 动作指导 + 表演指导 + 连续性专家 + 提示词工程师**，在内部完成导演决策、摄影语言映射、物理校验和表演设计后，只输出最终可直接粘贴到视频生成模型的提示词。

核心能力覆盖 11 个模块：

| 模块 | 作用 |
|---|---|
| 事件真值与优先级 | 身份/结构/核心动作优先于风格装饰，冲突时有明确保留顺序 |
| 任务识别与片段组织 | 自动判断单镜头/剧情/短剧/广告/动画等类型，按需拆分片段 |
| 空间与观察 | 建立主体距离、路径、遮挡、尺度等空间关系，选择合理景别 |
| 动作、表演与互动 | 动作按"触发→感知→反应→结果"设计，真人/非真人/多人各有规则 |
| 物理规律 | 现实/设定/风格化物理自动判断，保持内部一致 |
| 连续性与参考 | 强/弱连续继承，参考素材按身份/动作/场景/风格分职责使用 |
| 摄影语言 | 导演意图映射为景别、机位、焦段、景深、运镜、光线 |
| 风格系统与特效 | 多维度风格拆解，特效必须有来源、路径和结果 |
| 主体类型与声音 | 按主体结构选择表达通道，声画关系自动判断 |
| 提示词编译 | 内部判断全部转换为模型可识别的画面/声音描述，删除推理过程 |
| 结果评估与自检 | 提交前逐项校验，生成后按问题选择修复策略 |

## 适用场景

- 用 AI 视频模型（如可灵、即梦、Sora、Runway、Pika 等）生成视频时，需要高质量提示词
- 单镜头、剧情短片、连续短剧、人物表演、产品广告、操作演示、风景、动画等各类视频生成
- 需要保持多镜头连续性、人物一致性、物理合理性的复杂视频生成
- 不想自己琢磨摄影术语和提示词结构，希望 Claude 直接产出可执行结果

## 安装方式

### 前置要求

- 已安装支持自定义 Skill 的 Claude 客户端（Claude Desktop / Claude Code / 支持系统提示词注入的 Claude API 调用方式）

### 步骤

1. **克隆或下载本仓库**

```bash
git clone https://github.com/Nenny000/ai-video-director-skill.git
```

2. **将 Skill 目录放入 Claude 的 Skills 目录**

根据你使用的客户端，将 `ai-video-director-skill` 整个文件夹复制到对应位置：

- **Claude Desktop**：`~/Library/Application Support/Claude/skills/`（macOS）或 `%APPDATA%\Claude\skills\`（Windows）
- **Claude Code**：项目目录下的 `.claude/skills/`，或全局 skills 目录
- **API 方式**：将 `SKILL.md` 内容作为系统提示词（system prompt）注入你的调用

3. **重启 Claude 客户端**，Skill 即会被自动识别。

## 使用方法

安装后，直接用自然语言描述你想要的视频即可，例如：

```
帮我生成一个 5 秒的视频：一个穿红色风衣的女人在雨夜的东京街头快步走过，镜头从她的脚部特写慢慢上摇到面部，霓虹灯在湿地面反射。
```

Claude 会内部完成导演决策和提示词编译，最终输出类似这样的可执行提示词：

```
雨夜东京街头，地面湿润反射霓虹灯。穿红色风衣的女性从画面左侧快步走入，中近景跟随。镜头起始于脚部特写（皮鞋踏过积水溅起水花），缓慢上摇至面部，表情坚定，雨水沿发梢滴落。背景霓虹灯牌虚化，红蓝光线交替扫过面部。手持微晃，浅景深，5秒，终态：女性走出画面右侧，镜头停在空荡的霓虹街道。
```

你可以直接将输出的提示词粘贴到任意视频生成模型中使用。

### 进阶用法

- **提供参考图**：上传人物/场景/风格参考图，并说明每张图的用途（"这是主角长相""这是想要的场景""这是风格参考"），Skill 会按职责分配参考。
- **多镜头/短剧**：描述完整剧情，Skill 会自动拆分为多个片段并保持连续性。
- **生成后迭代**：把生成结果的问题告诉 Claude（"人物脸变了""动作不自然"），Skill 会选择重给参考、首尾帧、降载或重新生成等修复策略。

## 工作原理

Skill 的执行链：

```
理解目标 → 识别任务 → 锁定约束 → 判断复杂度 → 确定导演意图
→ 选择观察方式 → 映射摄影语言 → 设计连接 → 编译提示词 → 结果质检
```

所有内部分析、比较、推导和风险判断都在 Claude 内部完成，**最终只输出可执行的提示词**，不会把推理过程暴露给视频模型。

## 注意事项

- 本 Skill 是**纯系统提示词**，不包含任何可执行脚本，不调用外部 API，不收集任何数据。
- 生成质量取决于你使用的视频模型本身的能力；Skill 负责把需求翻译成模型能理解的最优提示词。
- 涉及真人参考图时，Skill 会优先锁定脸部结构和身份特征，不因风格化而重塑身份。
