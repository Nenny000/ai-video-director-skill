# 使用示例

以下示例严格按照 SKILL.md 的执行链与编译规则生成：最终输出只包含**主体、状态、动作、空间、摄影、光线、特效、声音、终态**，所有导演意图、表演判断和物理要求均已转换为可观察、可执行的画面描述，不保留抽象评价或推理过程。

---

## 示例 1：雨夜追逐 · 赛博朋克 · 可灵 Kling · 现实物理

**用户输入：**

```
用可灵 Kling 生成 8 秒视频，赛博朋克风格，高对比度霓虹色调。
一名穿黑色战术夹克的男特工在雨夜的霓虹巷弄中被追赶，他全速奔跑，
翻越一个半人高的金属路障，落地后顺势滑铲穿过积水区域，再起身继续跑。
镜头从侧面跟拍，翻越时切低角度，滑铲时镜头贴地。
物理设定：现实物理，雨水、水花、惯性和落地缓冲要真实。
```

**Skill 输出（可直接粘贴到可灵 Kling）：**

```
雨夜巷弄，地面大面积积水，两侧建筑外墙有红蓝霓虹招牌发光，雨水从画面上方垂直下落，密度中等。穿黑色战术夹克的男性（短发，面部有胡茬）从画面左侧全速跑入，身体前倾约 15 度，右臂前摆左臂后摆，脚步踏地溅起高度约 10 厘米的水花。

主体到达半人高（约 80 厘米）金属路障前 30 厘米处，右腿蹬地，左腿向前上方抬起跨越路障顶部，身体重心前移，夹克下摆因惯性向后扬起。翻越瞬间雨水从夹克肩部被甩落，沿切线方向飞出。

主体左脚先落地，膝盖弯曲约 45 度缓冲，身体重心继续向前下方降低，右腿向前滑出，臀部接近地面，双脚在积水中向前滑行约 1.5 米，积水向身体两侧推开形成高约 20 厘米的水墙，水花颗粒清晰，滑行路径上留下白色泡沫轨迹。

滑行结束后主体双手撑地，左腿收回蹬地，身体从蹲姿站起，恢复奔跑姿态，继续向画面右侧跑出。

摄影：起始侧面中景跟拍，镜头与主体同速平移；翻越路障时机位降至地面高度（约 15 厘米），仰拍主体跨越动作，路障在前景形成遮挡；滑铲时机位贴地（约 5 厘米），低角度侧拍，积水和水花在前景；主体起身后镜头拉远至中景，跟随主体跑出画面。

光线：左侧建筑红色霓虹招牌从左上方打亮主体左侧面部和肩部，右侧建筑蓝色霓虹招牌从右后方勾勒主体轮廓，地面积水反射红蓝光线随主体脚步晃动。

声音：雨水持续落下的环境声，脚步踏水声，翻越路障时金属轻微碰撞声，滑铲时水的撕裂声，起身时衣服摩擦声。

8秒，终态：主体跑出画面右侧，镜头停在贴地视角，巷弄中积水涟漪持续扩散，红蓝霓虹在水面反射，雨继续下落。
```

## 示例 2：腕表广告 · 极简高级 · 即梦 Dreamina · 现实物理

**用户输入：**

```
用即梦 Dreamina 生成 6 秒产品广告，极简高级风格，
浅灰背景，柔和影棚光。一块银色金属腕表从画面上方缓慢落入
一滩透明液体中，液体飞溅后腕表悬浮在液面上方缓慢旋转，
最后定格在表盘正面特写。物理设定：现实物理，
液体飞溅和悬浮要符合重力和表面张力。
```

**Skill 输出（可直接粘贴到即梦 Dreamina）：**

```
浅灰色无缝背景，画面中央下方有一滩直径约 20 厘米的透明液体（粘度接近水），液面平静，表面有柔和高光。银色金属腕表（圆形表盘，银色金属表带，表冠在 3 点钟位置）从画面上方约 30 厘米处开始下落，下落速度逐渐加快，表带因重力自然下垂并轻微摆动。

腕表表盘朝下接触液面瞬间，接触点液面凹陷，液体向四周推开形成环形波纹，波纹从接触点向外扩散，振幅逐渐减小。腕表继续下沉约 2 厘米后停止，液体从腕表边缘向上飞溅形成约 15 滴水滴，水滴大小不一（直径 2-8 毫米），沿抛物线轨迹向上向外飞出，到达最高点后受重力下落回落至液面，回落时产生小范围二次涟漪。

腕表从液体中升起，悬浮在液面上方约 5 厘米处，开始沿垂直轴缓慢旋转（顺时针，角速度约 30 度/秒），旋转时表带因离心力轻微向外展开，表身上残留的液体沿表面向下流动，在表镜下缘聚集形成水滴，水滴增大后滴落回液面。

摄影：起始俯拍（机位在正上方约 60 厘米，焦距 50mm），腕表下落时机位跟随下降至侧方 45 度中景，液体飞溅时焦点在腕表和飞溅水滴上，背景浅灰虚化；腕表悬浮旋转时机位环绕主体半圈（从左侧 45 度移动至正面），运镜平滑；最后推进至表盘正面特写（表盘占画面 60%），焦点在表盘中央指针和刻度上。

光线：顶部柔光箱从正上方均匀打光，表镜上形成长方形柔光反射，左侧 45 度有辅助光勾勒表壳边缘，右侧有弱反光板补光，阴影柔和，背景浅灰均匀无杂物。

特效：液体飞溅来源为腕表撞击液面，传播路径为环形波纹和抛物线水滴，结果为涟漪扩散和水滴回落；腕表悬浮来源为外力托举（不可见），结果为稳定旋转。

声音：腕表接触液面的"噗"声，液体飞溅的细碎水声，悬浮时轻微的金属嗡鸣，水滴回落的滴答声。

6秒，终态：表盘正面特写，银色金属表壳，白色表盘，黑色指针指向 10 点 10 分，表带在下方自然展开，液面在背景中保持平静，有微弱涟漪残留。
```

## 示例 3：西部酒吧 · 复古胶片 · Runway Gen-3 · 现实物理（3 镜头连续短剧）

**用户输入：**

```
用 Runway Gen-3 做一个 15 秒的 3 镜头短剧，复古西部片风格，
35mm 胶片质感，暖黄色调，颗粒明显。
剧情：一个穿棕色风衣戴牛仔帽的男人推开酒吧木门走进来，
酒吧里所有人停下动作看向他，他走到吧台前坐下，
酒保默默把一杯威士忌推到他面前。
物理设定：现实物理，注意木门铰链、风衣摆动、
冰块在酒杯中的碰撞。分三个镜头，保持人物和场景连续。
```

**Skill 输出（3 段连续提示词，可逐段粘贴到 Runway Gen-3）：**

### 镜头 1（0-5 秒）：推门进入

```
复古西部酒吧内部，木质墙壁，暖黄色煤油灯悬挂在天花板，空气中有轻微灰尘颗粒在灯光中漂浮。画面中央是一扇厚重的木质双开门（门高约 2.5 米，铁制铰链在左侧）。门从外侧被推开，左侧门扇向内打开约 90 度，铰链发出可见的金属转动，门底部在木地板上拖过留下轻微摩擦痕迹。

穿棕色长风衣（长度至膝盖下方）、戴深棕色牛仔帽的男性从门外走入，第一步踏入时风衣下摆因门外风势向后扬起，帽檐在面部投下阴影。他步伐沉稳，每一步靴子踏在木地板上发出可见的地板轻微震动。酒吧内部约 8 人（坐在吧台和圆桌旁）全部停止手中动作，头部转向门口方向，手中的酒杯停在半空，扑克牌停在桌面。

摄影：中景固定机位，从酒吧内部朝向门口，门在画面中央，主体从门外走入向镜头方向移动，景深较浅，焦点在主体面部，背景人物和酒吧环境轻微虚化。

光线：门外强烈日光从打开的门射入，在木地板上形成长方形亮光区域，主体从亮光区域走入酒吧内部暖黄色灯光区，面部从逆光剪影逐渐被暖光打亮，煤油灯从上方提供主光。

声音：木门铰链吱呀声，靴子踏木地板声，酒吧内原本的低语声和玻璃杯碰撞声突然停止，只剩煤油灯燃烧的细微嘶嘶声。

5秒，终态：主体走入酒吧内部约 3 米，站在门口和吧台之间，面向吧台方向，风衣下摆恢复静止，酒吧内所有人保持看向主体的姿态。

【连续性锁定：棕色长风衣、深棕色牛仔帽、男性面部特征、酒吧木质墙壁、暖黄煤油灯、门口位置、8 个背景人物位置和服装】
```

### 镜头 2（5-10 秒）：走向吧台

```
延续上一镜头终态。主体从站立位置向画面右侧的吧台走去，步伐匀速，风衣下摆随步伐左右轻微摆动，靴子每一步踏在木地板上。吧台为深色木质，高度约 1.1 米，台面上排列着透明玻璃杯和棕色酒瓶，吧台后方有镜面墙反射酒吧内部。

主体走到吧台前的高脚木凳前，右手扶住吧台边缘，左腿抬起跨过凳子横梁，身体下降坐下，坐下时风衣下摆铺在凳子周围，牛仔帽帽檐距离吧台上方约 20 厘米。主体坐下后双手放在吧台面上，背部挺直，面向吧台后方的酒保。

酒保（穿白色衬衫，黑色背带，留胡须）站在吧台后方，手中正在擦拭玻璃杯的动作停止，目光与主体接触，然后低头从吧台下方取出一个厚底透明威士忌杯，放在台面上，拿起一瓶棕色威士忌酒瓶，倾斜瓶口向杯中倒入液体，液体流入杯中形成漩涡，液面上升至杯子约 1/3 高度。

摄影：侧面中景跟拍，镜头从主体左侧跟随其走向吧台，主体坐下时机位固定在侧面，高度与吧台齐平（约 1.1 米），焦点在主体和酒保之间，背景镜面墙反射出酒吧内部。

光线：暖黄色煤油灯从上方打亮吧台区域，主体面部从侧面被暖光照亮，帽檐在眼睛上方形成阴影，吧台台面有酒瓶和玻璃杯的反射。

声音：靴子走路声，凳子木质轻微吱呀声，威士忌倒入玻璃杯的液体声，背景中有人低声清嗓子。

10秒，终态：主体坐在吧台前高脚凳上，面向酒保，双手放在吧台，威士忌杯中已有约 1/3 杯棕色液体，酒保持瓶姿势，酒瓶瓶口刚离开杯口。

【连续性锁定：同一主体（棕色风衣、牛仔帽）、同一酒吧、吧台位置、酒保（白衬衫黑背带）、威士忌杯、暖黄灯光、背景人物保持上一镜头位置】
```

### 镜头 3（10-15 秒）：酒被推过来

```
延续上一镜头终态。酒保将手中的威士忌酒瓶放回吧台台面（瓶子直立，标签朝前），然后右手手掌放在威士忌杯杯身侧面，手指握住杯子，将杯子沿吧台表面向主体方向水平推动约 40 厘米。杯子在木质台面上滑动，杯底与台面摩擦，杯中液体因惯性向推动反方向倾斜，液面形成约 10 度斜面，液体晃动后逐渐恢复水平。

杯子滑动到主体右手前方约 10 厘米处停止，酒保松开手。主体低头看向杯子，右手抬起握住杯身（拇指和食指中指握住杯子中部），将杯子举至嘴边，头部微微后仰，杯口接触嘴唇，液体从杯中流入口腔，喉咙可见吞咽动作（喉结上下移动一次）。主体将杯子放回吧台，杯底接触台面发出轻微碰撞声。

主体喝完后将杯子放回原位，头部抬起，目光直视前方（酒保方向），面部表情保持不变，右手松开杯子放回吧台。酒吧背景中，一个坐在圆桌旁的男人低头继续喝自己的酒，另一个人点燃一支香烟，火柴划燃产生瞬间橙黄色火焰。

摄影：吧台正面近景，机位在吧台后方朝向主体，焦距 85mm，浅景深，焦点在威士忌杯和主体右手、面部，背景酒保和酒吧环境虚化。运镜：杯子被推动时焦点跟随杯子移动，主体举杯时焦点转移至主体面部。

光线：暖黄色煤油灯顶光，吧台台面有杯子和酒瓶的柔和反射，背景中火柴点燃的瞬间橙黄色光在画面右侧闪烁，主体面部被暖光均匀打亮，帽檐阴影保持在眼睛上方。

声音：杯子在木吧台滑动的摩擦声，液体晃动声，杯子放回台面的碰撞声，吞咽声，背景火柴划燃声，酒吧内逐渐恢复低沉的环境音。

15秒，终态：主体坐在吧台前，威士忌杯中剩余约 1/4 液体，杯子在主体右手旁，主体目光直视前方，背景酒吧恢复轻微活动，暖黄灯光持续。

【连续性锁定：同一主体、同一酒吧、同一酒保、威士忌杯（液体量减少）、吧台位置、暖黄灯光、背景人物延续上一镜头状态】
```

## 编译规则对应说明

| SKILL.md 规则 | 示例中的体现 |
|---|---|
| 最终提示词只含主体/状态/动作/空间/摄影/光线/特效/声音/终态 | 每段输出均按此结构组织，无抽象评价 |
| 动作遵循触发→感知→处理→反应→结果 | 示例1：看到路障→蹬地→跨越→落地缓冲→继续跑 |
| 运镜写成起始状态→摄影变化→关注转移→结束落点 | 每个示例的摄影段落均按此格式 |
| 特效必须有来源、传播路径和结果 | 示例2：液体飞溅来源=腕表撞击，路径=抛物线，结果=涟漪回落 |
| 物理规律：重量/惯性/重力/支撑/碰撞 | 示例1落地缓冲、示例2液体重力下落、示例3风衣摆动 |
| 连续性锁定必要项 | 示例3每段末尾标注身份/结构/位置/方向/道具/光线 |
| 删除内部推理、评分、无生成价值信息 | 输出中无"导演意图""我认为""评分"等元信息 |
| 情绪转换为可观察状态 | 示例3"紧张"转换为"所有人停止动作、酒杯停在半空" |
