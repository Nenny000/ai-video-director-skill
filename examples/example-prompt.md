# 使用示例

以下示例均包含**风格设定**、**具体视频模型**和**物理设定**三个要素，展示 Skill 如何将它们编译为可执行提示词。

---

## 示例 1：赛博朋克 · 可灵 Kling · 现实物理

**用户输入：**

```
用可灵 Kling 生成一个 6 秒视频，赛博朋克风格。
一个穿透明雨衣的女特工在雨夜的霓虹巷弄中快速奔跑，
跳过一个积水坑，落地时水花溅起，镜头侧面跟随。
物理设定：现实物理，雨水和水花要真实。
```

**Skill 输出（可直接粘贴到可灵 Kling）：**

```
赛博朋克风格，雨夜霓虹巷弄，地面大面积积水反射红蓝霓虹招牌。穿透明雨衣的女性从画面左侧快速跑入，身体前倾，右臂前摆左臂后摆，脚步踏地溅起真实水花。到达积水坑时双腿弯曲蹬地起跳，身体腾空约 30 厘米，雨衣下摆因惯性上扬，雨滴在空中保持直线下落轨迹。落地时右脚先触地，膝盖缓冲，积水向两侧溅起高度约 15 厘米的水花，水花颗粒清晰。侧面中景跟拍，镜头与人物同速平移，浅景深，背景霓虹牌虚化呈色散光斑。6秒，终态：女性跑出画面右侧，镜头停在积水坑涟漪扩散的巷弄。
```

## 示例 2：宫崎骏手绘动画 · 即梦 Dreamina · 低重力物理

**用户输入：**

```
用即梦 Dreamina 生成 8 秒视频，宫崎骏手绘动画风格，
柔和水彩质感。一个小女孩在漂浮的云朵岛屿上奔跑，
她的头发和裙摆缓慢飘动，身边有几只发光的小精灵环绕。
物理设定：低重力环境（约地球 1/6 重力），
跳跃和下落都比现实缓慢，物体漂浮感强。
```

**Skill 输出（可直接粘贴到即梦 Dreamina）：**

```
宫崎骏手绘动画风格，柔和水彩质感，天空淡蓝渐变，蓬松云朵岛屿漂浮。小女孩在云朵表面奔跑，步伐轻盈，每一步踩下云朵轻微凹陷后缓慢回弹。深棕色长发和白色裙摆以低重力节奏缓慢飘动，发丝末端在空中停留时间比现实长 2-3 倍。三只拳头大小的发光小精灵（暖黄色光晕）围绕女孩飞行，飞行轨迹为缓慢螺旋上升，翅膀扇动频率低。女孩起跳时身体缓慢上升约 50 厘米后缓慢下落，整个腾空过程约 2 秒，落地时云朵大面积凹陷再缓缓恢复。中景固定机位，柔和侧光，画面边缘有轻微水彩晕染。8秒，终态：女孩站在云朵边缘望向远方，小精灵停在她肩头，头发和裙摆持续缓慢飘动。
```

## 示例 3：复古胶片 · Runway Gen-3 · 现实物理（多镜头短剧）

**用户输入：**

```
用 Runway Gen-3 做一个 12 秒的 3 镜头小短片，
复古 16mm 胶片风格，颗粒感和轻微漏光。
剧情：男人在老式电话亭里打电话，表情从平静变为震惊，
挂断电话后推门冲出去，外面是 1970 年代的纽约街头。
物理设定：现实物理，注意胶片时代的道具质感
（旋转拨号盘、玻璃门弹簧、风衣布料）。
分三个镜头，保持人物和场景连续。
```

**Skill 输出（3 段连续提示词，可逐段粘贴到 Runway Gen-3）：**

**镜头 1（0-4 秒）：**

```
复古 16mm 胶片风格，明显颗粒感，画面边缘轻微漏光呈暖橙色。1970 年代纽约街头夜色，金属电话亭内，穿深棕色风衣的男人手持听筒贴在耳边，另一只手插在口袋里，表情平静。电话亭内顶灯偏黄，玻璃上有雨水痕迹和街灯反射。中近景固定机位，透过电话亭玻璃拍摄，玻璃上有轻微污渍。4秒，终态：男人表情开始变化，眉头微微皱起。
【连续性锁定：深棕色风衣、短发、金属电话亭、夜晚街道、暖黄灯光】
```

**镜头 2（4-8 秒）：**

```
复古 16mm 胶片风格，颗粒感持续。电话亭内，男人表情转为震惊，眼睛睁大，握听筒的手指收紧，身体微微前倾。他迅速用右手挂断电话（听筒扣回机座发出可见的撞击动作），左手推开电话亭玻璃门，门因弹簧装置向外弹开，风衣下摆随转身动作扬起。从中近景切换到侧面中景，镜头跟随男人转身动作。8秒，终态：男人一只脚跨出电话亭，身体面向街道。
【连续性锁定：同一男人、深棕色风衣、同一电话亭、夜晚、门向外打开状态】
```

**镜头 3（8-12 秒）：**

```
复古 16mm 胶片风格，颗粒感和漏光。1970 年代纽约街头，男人从电话亭快步走出，风衣在身后飘动，他左右张望后向画面左侧快步走去。背景有老式汽车（黄色出租车）驶过，街灯发出暖黄色光晕，行人穿着时代特征服装（宽领衬衫、喇叭裤）从旁经过。中景跟随镜头，手持微晃，模拟纪录片质感。12秒，终态：男人走向街道远处，背影逐渐变小，电话亭留在画面右侧。
【连续性锁定：同一男人、深棕色风衣、夜晚街道、暖黄灯光、电话亭位置】
```

## 要素对应说明

| 示例 | 风格 | 具体模型 | 物理设定 |
|---|---|---|---|
| 示例 1 | 赛博朋克 | 可灵 Kling | 现实物理（雨水/水花真实） |
| 示例 2 | 宫崎骏手绘动画 | 即梦 Dreamina | 低重力（1/6 G，漂浮缓慢） |
| 示例 3 | 复古 16mm 胶片 | Runway Gen-3 | 现实物理（道具质感/弹簧/布料） |

Skill 会将用户输入中的风格、模型和物理要求自动转换为提示词中可观察、可执行的画面描述，不会在最终输出中保留抽象的风格标签或推理过程。
